# Project Proposal: AI in Drug Discovery

## 1. Title
AI in Drug Discovery: An Introduction to Computational Compound Ranking

## 2. Background
Drug discovery combines biology, chemistry, pharmacology, and clinical research. AI methods can analyse patterns in large datasets and help researchers prioritise compounds for additional investigation.

## 3. Problem Statement
Early-stage drug discovery may involve evaluating many possible compounds. This project explores, at an introductory level, how computational analysis can organise and rank candidates while recognising that simple scores are not evidence of safety or effectiveness.

## 4. Aim
To understand the role, potential benefits, and limitations of AI in drug discovery.

## 5. Objectives
- Explain the basic drug-discovery process.
- Identify examples of AI use in pharmaceutical research.
- Demonstrate a simple ranking workflow with fictional data.
- Discuss why predictions require scientific validation.

## 6. Methodology
1. Review reliable introductory resources.
2. Summarise AI applications in drug discovery.
3. Run the provided Python script using fictional example data.
4. Observe how the weighted score determines the ranking.
5. Discuss limitations and possible improvements.

## 7. Tools
- GitHub for version control and project presentation.
- Python 3 for the educational demo.
- A text editor or GitHub web editor.

No external Python packages are required for the included demo.

## 8. Expected Outcomes
The project will provide a basic understanding of computational compound ranking and explain why real drug discovery requires high-quality datasets, validated methods, laboratory research, and clinical evaluation.

## 9. Scope and Safety
This is an educational demonstration only. It does not analyse real compounds, predict medical outcomes, recommend treatments, or replace expert research.

## 10. Conclusion
The project introduces how computational methods can support research decisions while emphasising that AI-generated results must be evaluated critically.
